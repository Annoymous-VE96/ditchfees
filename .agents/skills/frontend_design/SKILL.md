# Frontend Design Skill

- Maintain responsive grid system (mobile-first approach).
- Use semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`).
- Implement clean, reusable component architecture.
- Ensure cross-browser compatibility and optimized performance.
