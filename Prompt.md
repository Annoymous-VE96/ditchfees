# Task: Redesign homepage — https://ditchfees.com.au

## 1. Research (do this first, don't skip)
- Visit the site, extract what they do, their services, tone, and any pain points they solve.
- Find their Google Business listing: pull star rating, review count, and 4+ real 5-star reviews (verbatim, with names + dates).
- Note real numbers if available (years in business, jobs done, response time). If genuinely unavailable, flag it instead of inventing one.

## 2. Copy
Rewrite all homepage copy from scratch using the research above. Follow the voice rules in `template.md` §4 (plain-spoken, Australian tone if applicable, no em dashes, no emojis, no corporate filler words).

## 3. Layout & design
Build the page using `@template.md` as the exact spec — section order, rules, and conversion checklist are non-negotiable.
Pick ONE skin (A/B/C/D) from `template.md` §2.1 based on what fits Ditchfees' existing branding/industry. State which skin you chose and why in one line before building.
Decide case-by-case whether the optional inserts (Founder Bio, Pain-Point Empathy Block, Blog Teaser) apply — only include ones that fit what you find on the site.

## 4. Images
Generate all needed images using Antigravity's built-in image generation. Keep them light-themed per `template.md` §0 rule 13 (bright source photos, subtle dark gradient overlay only — never baked-in darkness). Do not use stock photos or external image tools.
Use `Images/Google.svg` for the Google rating badge icon (template §0 rule 4).

## 5. Output scope
Homepage only. One single-page build per `template.md` §6.

## 6. Before finishing
Run the full checklist in `template.md` §5 and confirm each item.
